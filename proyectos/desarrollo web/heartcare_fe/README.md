# Heartcare_fe

## Descripción General

Heartcare_fe es una interfaz frontend diseñada para clínicas medicas que permite a los profesionales de la salud gestionar pedidos, solicitudes y datos de pacientes de forma centralizada y eficiente.

## Características

- **Gestión de Pedidos:** Panel para visualizar, aprobar y administrar solicitudes de pacientes.
    
- **Control de Pacientes:** Expedientes digitales y seguimiento de peticiones medicas.
    
- **Interfaz de Medicos:** Dashboard optimizado para agilizar el flujo de trabajo clinico. (en progreso)
    

## Tecnologias

- **Frontend:** HTML, CSS, JavaScript (React.js)
- **Backend:** Arquitectura de capas basada en express.js y usando una base de datos de PosgreSQL.
